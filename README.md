# MindSwitch

毎朝、約3分の4ステップで今日のマインドをセットするPWA（スマートフォン向けWebアプリ）です。

- ビルド不要・Node不要・npm不要（React/Vue/Viteなども不要）
- ファイルをそのままGitHubへアップロードするだけで公開できます
- **スマートフォンだけ**で公開・更新できる構成にしてあります

---

## 1. ファイル構成

```
MindSwitch/
├── index.html                  … アプリ本体（このファイルを開けば動きます）
├── style.css                   … デザイン（CSSは1ファイルのみ）
├── app.js                      … 画面・操作ロジック
├── storage.js                  … データの保存・読み込み・バックアップ層
├── manifest.webmanifest        … PWA設定（ホーム画面追加用）
├── service-worker.js           … オフライン起動・更新通知
├── icon-192.png                … アイコン（通常・小）
├── icon-512.png                … アイコン（通常・大）
├── icon-maskable-192.png       … アイコン（マスク対応・小）
├── icon-maskable-512.png       … アイコン（マスク対応・大）
├── legacy.html                 … 旧・単一HTML版（バックアップ・予備用）
├── README.md                   … このファイル
├── APP_SPEC.md                 … 仕様書
├── USER_GUIDE.md                … 使い方
├── CHANGELOG.md                … 更新履歴
└── LICENSE
```

フォルダ分け（css/ js/ icons/ など）は行っていません。すべて同じ階層に置くだけで動きます。

---

## 2. GitHub Pagesでの公開手順（スマートフォンのみでOK）

1. GitHubアプリ、またはスマホのブラウザでGitHubにログインします。
2. リポジトリを新規作成します（例：`MindSwitch`）。Public（公開）にしてください。
3. リポジトリ内で「Add file」→「Upload files」を選び、上のファイル構成のファイルを**すべて同じ階層に**アップロードします。
   - サブフォルダは作らないでください。
4. コミットします（コミットメッセージは自由）。
5. リポジトリの「Settings」→「Pages」を開きます。
6. 「Source」を `Deploy from a branch` にし、Branchを `main`（または既定のブランチ）、フォルダを `/(root)` に設定して保存します。
7. しばらく待つと、`https://ユーザー名.github.io/リポジトリ名/` でアプリが公開されます。
8. スマホのブラウザでそのURLを開き、「ホーム画面に追加」を行うとアプリのように使えます。

---

## 3. 更新方法（スマホだけで運用）

1. GitHubアプリまたはブラウザでリポジトリを開きます。
2. 変更したいファイル（例：`app.js`）をタップし、鉛筆マーク（Edit）で直接編集するか、
   「Upload files」で新しい版を同名で上書きアップロードします。
3. コミットすれば、数十秒〜数分でGitHub Pagesに反映されます。

### 更新時の注意（キャッシュについて）

`service-worker.js` の一番上にある `CACHE_VERSION` の数字は、内容を更新するたびに1つ増やしてください。

```js
const CACHE_VERSION = "mindswitch-cache-v1"; // 次回更新時は v2, v3 …
```

これを増やさないと、利用者の端末に古いキャッシュが残り、更新内容が反映されないことがあります。
（アプリ側には更新検知・「更新する」通知の仕組みが入っていますが、`CACHE_VERSION` を変更しないとそもそも新しい内容だと認識されません。）

## 4. PWAとしての動作

- ホーム画面への追加（Android/iOS）に対応
- オフラインでも起動できます（一度読み込んだ後はネット接続不要）
- アプリ更新時は自動で新しい内容を検知し、「新しいバージョンがあります」という通知が出ます。タップすると最新版に切り替わります。
- GitHub Pagesの提供するHTTPS配信にそのまま対応
- すべて相対パス（`./`）で参照しているため、リポジトリ名がURLの一部に含まれる場合でも動作します。

---

## 5. データについて

- 入力内容は**この端末の中だけ**に保存されます。外部サーバーへの送信は行いません。
- 保存にはIndexedDBを主に使用し、localStorageを補助として併用します。壊れたデータは自動検出し、直近のバックアップから復旧を試みます。
- 既存の旧バージョン（`legacy.html`など）で保存したデータも、IndexedDB名・localStorageキー・データ構造を変更していないため、そのまま引き継がれます。

より詳しい仕様は `APP_SPEC.md`、使い方は `USER_GUIDE.md` をご覧ください。
